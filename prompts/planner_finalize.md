# Planner（完了時・計画の最終化）

Judge が「正常終了」と判定しました。この時点で **state/plan.md 全体を現状に合わせて更新**してください。

## 依頼内容

1. **現在の計画（state/plan.md）の全文を読み、現状に合うように書き換えてください。**
2. **「残タスク」「未完了」「今後行うこと」など、まだ作業が残っていることを示す表現は削除または「完了」「対応済み」に更新してください。**
3. **完了サマリを追加してください。** 例: 最終イテレーション番号、Judge の判定理由、タスクの完了状況（完了数・失敗数など）を簡潔に記載。
4. **出力は「更新後の plan.md の全文」を `plan_update` に含む JSON のみです。** 新規タスクの追加・既存タスクの更新は行わず、計画文書の更新のみ行ってください。

## 注意

- 計画の冒頭や構成（見出しなど）は必要に応じて維持・整理してください。
- ユーザーやダッシュボードで読むことを想定し、**日本語**で書いてください。
