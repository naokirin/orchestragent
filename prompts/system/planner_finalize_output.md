## 出力形式（必須）

応答テキストの中にのみ、以下の JSON 形式で出力してください。**plan_update に「更新後の plan.md の全文」を入れてください。** タスクの追加・更新は行いません。

```json
{{
  "plan_update": "更新後の計画のMarkdown全文（state/plan.md にそのまま保存する内容）",
  "reasoning": "どのように計画を更新したかの簡潔な説明（任意）"
}}
```

- **plan_update**: 必ず含めてください。現状に合わせた計画の全文（完了サマリ含む）です。
- **reasoning**: 省略可能です。
- ユーザー向け表示のため、**日本語**で書いてください。
